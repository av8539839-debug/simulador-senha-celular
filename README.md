# 📱 Phone Lock Screen Simulator (PIN Code)

Um projeto interativo desenvolvido com **HTML5**, **CSS3** e **JavaScript** que simula a tela de bloqueio de um smartphone com validação de senha numérica (PIN).

## 🚀 Funcionalidades

* **Design de Mockup de Celular:** Interface estilizada simulando um smartphone moderno (com moldura e detalhes visuais).
* **Feedback Dinâmico:** Conforme o usuário clica nos botões numéricos, pontos indicadores mascaram os dígitos inseridos.
* **Validação de Senha:** Verifica se a sequência digitada está correta, exibindo mensagens de sucesso ("Desbloqueado!") ou erro ("Incorreto!").
* **Totalmente Responsivo e Estilizado:** Uso de Flexbox/Grid e efeitos modernos de sombra e cores (`glassmorphism`).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura da página e dos elementos da interface.
* **CSS3:** Estilização avançada, variáveis, layout do mockup e animações/transições.
* **JavaScript (Vanilla):** Lógica de captura de cliques, gerenciamento de estado da senha e validação condicional.
